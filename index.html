02 — Norte Sistemas

Software a medida, con norte.

El nombre con el que desarrollo software. Hoy es un proyecto de una sola persona; la meta es convertirlo en una empresa de soluciones.

Qué hago

  • Sistemas de gestión a medida, como Pro-Athletic para gimnasios.
  • Sitios web como el de la farmacia o el de Service Cool.
